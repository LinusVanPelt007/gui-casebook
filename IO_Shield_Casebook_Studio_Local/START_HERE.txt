I/O SHIELD CASEBOOK STUDIO — LOCAL v0.1.1

This app runs on your own computer and works offline. Nothing to install.

1. Download the zip for your computer (Windows, Mac, or Linux).
2. Unzip it into a folder you keep, such as Documents. Do not run it from
   inside the zip.
3. Double-click the Start file:
   Windows: Start_Casebook_Windows.cmd
     If Windows says it protected your PC, click More info, then Run anyway.
   Mac: Start_Casebook_Mac_Linux.command
     If macOS blocks it the first time, open System Settings, go to
     Privacy & Security, scroll down, and click Open Anyway.
   Linux: run sh Start_Casebook_Mac_Linux.command in a terminal.
4. Your browser opens http://127.0.0.1:8765 (localhost:8765 also works).
   If it does not, paste that address into your browser.
5. Keep the launcher window open while working. Close it to stop the app.

Copied the app from source instead of a download? It needs Node.js 22.13
or newer from https://nodejs.org/en/download. The launchers use it
automatically when there is no runtime folder.

USING YOUR CASEBOOK
- Drop your casebook .xlsx on the start page, or use the casebook menu
  (top right) > Import casebook.
- Import occurs locally. The original workbook is retained untouched.
- Open a case to log sessions, add proof, claim skills, and write portfolio
  stories. IDs, hours, and fields from the case are filled in for you.
- Casebook menu > Download Excel saves an updated revision.
- Download Excel + proof saves a ZIP with the workbook, uploaded supporting
  files, and revision history. Extract the complete bundle together.
- Open exported Excel files in Excel or LibreOffice to recalculate formulas.
- Updated revisions are separate files; the original spreadsheet on your
  computer is not edited in place.

WHERE YOUR DATA LIVES
The app creates a data\ folder beside server.mjs:
  data\casebooks.sqlite = imported record data, edits, file metadata, history
  data\objects\ = original workbooks and uploaded proof files
Browser cache and localStorage do not hold your authoritative records.
Closing the browser or restarting the app does not erase saved records.

BACKUP / MOVE TO ANOTHER COMPUTER
Stop the app, then copy the entire data folder to a secure backup location.
To migrate, install/extract this app on the other computer and place that
data folder beside server.mjs before launching. Excel + proof exports provide
portable document copies; the data folder is the complete workspace backup.
For an app upgrade, preserve data and replace only the application files.
The app does not sync with the hosted pilot. To transfer records from there,
export an updated workbook and upload it here. Proof files must be downloaded
and reattached locally; cross-app attachment mappings do not migrate yet.

LOCAL OPERATION
The server listens only on 127.0.0.1. Other computers cannot connect.
No login is required: this is a personal application for the current computer.
It makes no outbound network requests. Use your normal OS account permissions,
disk encryption, and backup controls for access to the data folder.
Do not expose this version to the internet or treat it as a multi-user server.

CURRENT LIMITS
- Imports support the supplied v3 workbook layout, not arbitrary Excel files.
- Up to 20 casebooks, 30 MB per workbook, 10 MB per attachment, and 100 proof
  files totaling 40 MB per casebook.
- Entry capacity follows the template's fixed summary ranges: 250 cases,
  500 sessions, 750 proof records, 1,000 skill claims.
- T4/T5 hours remain blank. New claims remain pending review.
- No reviewer invitations, client/vendor inbox, malware scanning, public
  portfolio hosting, or operational evidence chain-of-custody workflow.
- Portfolio exports require cleanup confirmation and explicit sharing
  acknowledgment; they include draft text, not private attachments.
- On the roadmap: a blank casebook template and a New casebook option.

TROUBLESHOOTING
- If port 8765 is already in use, an app window may already be running.
  Windows: set CASEBOOK_PORT=8766 then run node server.mjs --open.
  Mac/Linux: CASEBOOK_PORT=8766 node server.mjs --open.
- If you cannot write to the app folder, move it to a writable Documents
  folder. Avoid Program Files and other protected directories.
- Advanced: set CASEBOOK_DATA_DIR to an absolute folder path to keep records
  outside the application folder. A fresh path starts an empty workspace.
